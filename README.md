# 中欧正面 1949–1991

冷戦期の中欧正面で、ソ連・ワルシャワ条約機構（WP）とNATOがどんな戦略・作戦術・戦争計画を持っていたかを時期ごとに対照し、師団単位の戦闘序列で「計画が想定した戦争」を動かして確かめるための単一HTMLページです。

`index.html` をブラウザで開けばそのまま動きます（d3 と topojson は cdnjs から読み込みます）。

## 内容

- **§1 時期区分**：1950年代から1980年代までを五つの時期に分け、東西の戦略・作戦・計画を並べる
- **§2 中欧正面シミュレーター**
  - デンマーク・バルト海出口を含む10の侵攻軸と、1989年前後の戦闘序列（NORTHAG / CENTAG / BALTAP、在独ソ連軍・東独軍・ポーランド軍・チェコスロヴァキア軍ほか）
  - WPの事前動員とNATOの警報期間（情報が動員を察知するまで＋同盟が決定するまで）
  - 航空戦、大西洋の制海と米国からの増援、D+60までの後続梯団と戦略予備
  - 西ベルリンの攻略（ツェントルム作戦）、オーストリアの中立侵犯、北ノルウェー、化学兵器（効果はスライダーで調整）
  - ライン川を越えた後の主攻の切り替え（パリ／英仏海峡）、フランスの本土防衛と「最後の警告」
  - 核の敷居と分岐（計算を止める／選択的初使用／エスカレーション）、同盟内協議の遅れ、西ドイツの自国領内での使用拒否
  - **不確実性**：評価の割れていた数字を幅で揺らして数百回回し、核の敷居・ライン川・英仏海峡・パリへの到達の確率と、結果を最も左右する要因（順位相関）を示す
- **§2-2〜2-5** 戦闘序列、軸をまたぐ梯団、時代別の兵力と師団編成、主な師団の来歴
- **核パネル**：戦域核から戦略核までの段階別の民間人被害の推計（カルト・ブランシュ演習と OTA 1979 の推計にもとづく）
- **§3〜§5** 作戦術と戦術、公開された計画と演習、評価論争（ミアシャイマー、ポーゼン、コーエンほか）
- **§6** モデルの前提と出典

## 注意

シミュレーターの数字は相対比較のためのもので、実際の戦闘結果や現実の確率を表すものではありません。ワルシャワ条約機構側の軸への部隊の割り当ては計画文書ではなく、駐屯地と西側の見積もりからの想定です。前提の詳細はページの§6にあります。

## 構成

```
index.html          ビルド済みの単一ページ（GitHub Pages でそのまま公開できる）
build.py            src/ から index.html と dist/artifact.html を組み立てる
src/
  page.src.html     本文と CSS の骨格
  sim_section.html  シミュレーター部分の HTML
  css_add.css       追加の CSS
  model.js          戦闘序列とシミュレーションの計算（Node からも読み込める）
  part_main.js      地図・操作パネル・プリセット・核パネル
  part_mc.js        不確実性（モンテカルロ）パネル
  part_eras.js      時代別の兵力・師団編成・師団紹介
  part_echelon.js   梯団の表
  part_periods.js   時期区分
  part_geo.js       地図の地物
  data/eu.json      欧州の TopoJSON（Natural Earth / world-atlas 2.0.2 から抜粋）
tests/
  model.test.js     モデルの回帰テストとモンテカルロの要約
  ui_test.py        ビルド済みページのヘッドレス確認（Playwright）
```

## ビルドとテスト

```sh
python3 build.py          # index.html と dist/artifact.html を更新
npm install               # テスト用（d3-geo ほか）
npm test                  # モデルのテスト
pip install playwright && python3 -m playwright install chromium
npm run test:ui           # ページの表示確認
```

## GitHub Pages で公開する

リポジトリの Settings → Pages で「Deploy from a branch」を選び、ブランチを `main`、フォルダを `/ (root)` にすると、`index.html` がそのまま公開されます。
